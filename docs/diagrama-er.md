# Diagrama ER - DBA_COMPRAS

```mermaid
erDiagram
    TBL_CLIENTES ||--o{ TBL_TARJETAS : tiene
    TBL_MARCAS ||--o{ TBL_TARJETAS : clasifica
    TBL_CATEGORIAS ||--o{ TBL_PRODUCTOS : agrupa
    TBL_CLIENTES ||--o{ TBL_ENC_COMPRAS : realiza
    TBL_TARJETAS ||--o{ TBL_ENC_COMPRAS : paga
    TBL_ENC_COMPRAS ||--o{ TBL_DET_COMPRAS : contiene
    TBL_PRODUCTOS ||--o{ TBL_DET_COMPRAS : vendido_en

    TBL_CLIENTES {
        NUMBER ID_CLIENTE PK
    }

    TBL_MARCAS {
        NUMBER ID_MARCA PK
    }

    TBL_TARJETAS {
        NUMBER ID_TARJETA PK
        NUMBER ID_CLIENTE FK
        NUMBER ID_MARCA FK
    }

    TBL_CATEGORIAS {
        NUMBER ID_CATEGORIA PK
    }

    TBL_PRODUCTOS {
        NUMBER ID_PRODUCTO PK
        NUMBER ID_CATEGORIA FK
    }

    TBL_ENC_COMPRAS {
        NUMBER ID_COMPRA PK
        NUMBER ID_CLIENTE FK
        NUMBER ID_TARJETA FK
    }

    TBL_DET_COMPRAS {
        NUMBER ID_COMPRA FK
        NUMBER ID_PRODUCTO FK
    }
```

Relaciones validadas desde el diccionario de Oracle:

- `TBL_TARJETAS.ID_CLIENTE` -> `TBL_CLIENTES.ID_CLIENTE`
- `TBL_TARJETAS.ID_MARCA` -> `TBL_MARCAS.ID_MARCA`
- `TBL_PRODUCTOS.ID_CATEGORIA` -> `TBL_CATEGORIAS.ID_CATEGORIA`
- `TBL_ENC_COMPRAS.ID_CLIENTE` -> `TBL_CLIENTES.ID_CLIENTE`
- `TBL_ENC_COMPRAS.ID_TARJETA` -> `TBL_TARJETAS.ID_TARJETA`
- `TBL_DET_COMPRAS.ID_COMPRA` -> `TBL_ENC_COMPRAS.ID_COMPRA`
- `TBL_DET_COMPRAS.ID_PRODUCTO` -> `TBL_PRODUCTOS.ID_PRODUCTO`
